# RefViz bootstrap study

This directory contains the isolated benchmark for the pinned RefViz project.
The common scoring scheme is in `EXPERIMENT_NOTES.md`; each path keeps its own
artifact and conclusion as a named file:

```text
path-a-domain-record.md
path-b-projections.md
path-c-change-proposal.md
```

The submodule at `project/` is external and must only be changed in its own
repository.
