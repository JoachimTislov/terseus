# AI-VCS bootstrap study

This directory contains the study protocol and evidence boundary for the
selected AI-native VCS project stored as the `project/` Git submodule.

Keep path-specific artifacts separate:

```text
experiments/002-aivcs-bootstrap/
  EXPERIMENT_NOTES.md
  path-a-domain-record/
  path-b-projections/
  path-c-change-proposal/

```

Do not place study conclusions inside `project/`. Update the selected
project only through its own repository and record the resulting commit here.
